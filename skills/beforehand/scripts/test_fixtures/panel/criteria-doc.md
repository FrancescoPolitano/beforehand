# Weekly signal digest

Cadence: weekly
Distribution: every desk on the shared drive

A digest that arrives after the fact is a newsletter. This one is built so that a desk hears
about a change before the desk next to it does, and so that every number in it can be traced
back to the row that produced it.

## What the digest carries

| Signal | Source | Lead time | Confidence |
|---|---|---|---|
| Depot queue length | dispatch export | | high |
| Fuel card spend | card statement | | medium |

**Lead time:** to be agreed with the desks once the first four weeks have run.

The two entries above were both written up the morning after they appeared in the public
feed, which is to say the digest reported them and did not anticipate them.

## What the digest costs

The downside comes first here, before any saving is claimed: two desk-hours a week to
compile, and a fortnight of double running while the old report is retired.

Savings are measured against the named baseline of the last four quarters of manual
compilation, which is written into the appendix and agreed before the first issue ships.
