# Norm anchors — one distinctive phrase per norm of the evidence model (SPEC-0.2 FR-3.2).
#
# Every phrase below is a literal substring of skills/beforehand/references/evidence-model.md,
# which is the one file allowed to state these rules. dev/check_norms.sh greps each phrase
# across skills/beforehand/ and requires exactly one matching file: a second file means the
# rule has been restated instead of cited by anchor.
#
# Rules: one phrase per line; it must sit on a SINGLE line in EVERY file where the norm
# appears (grep is line-based, so a phrase that wraps in the duplicate silently reports
# one file and hides it); `#` and blank lines are ignored. The phrase is checked with
# grep -F, so punctuation and case are literal. Several anchors are therefore fragments
# of their sentence, cut to what fits one line on both sides.
#
# Scope: this file covers the norms of the evidence model. Norms that belong to a flow
# (the two-file isolation rule of review.md, the lint gate's two legal exits in
# authoring.md, the calibration accounting) are tracked in docs/ARCHITECTURE.md's
# rule table instead; they are not anchored here, because an anchor phrase that is not in
# evidence-model.md cannot be checked against "stated once, in that file".
#
# Not anchorable: the canonical empty-section form `no evidence as of <date>` is also a
# string in scripts/coverage.py, which parses it, so its file count can never be 1. The
# empty-section norm is anchored on its rationale clause instead.
